In addition, for JavaScript, for Part 3, I improved the Paws & Polish Dog Grooming website by adding an external JavaScript file called script.js to make the website more interactive, functional and user-friendly. I introduced several features, including an interactive image gallery, service searching and sorting, booking form validation and contact form validation. These improvements were made to allow visitors to interact with the website more easily instead of only viewing static information.

For the Gallery page, I added a JavaScript lightbox feature that allows users to click on an image and view it in a larger format without leaving the page. This makes it easier for customers to view the before-and-after grooming photographs. I also improved the Services page by introducing a search feature that allows visitors to search for specific grooming services. In addition, I added a sorting option that allows the services to be arranged alphabetically from A to Z or Z to A. These features make it easier for customers to find the information they need without having to scroll through every service.

For the Booking page, I added JavaScript form validation to check that customers complete the required information before submitting their booking requests. I used the event.preventDefault() method to prevent the page from refreshing when the form is submitted. Once the required information has been entered correctly, the website displays a confirmation message to inform the customer that the demonstration booking was submitted successfully. I also applied similar functionality to the Contact page, where visitors can complete an enquiry form and receive a confirmation message. After a successful demonstration submission, the contact form automatically clears its fields. These forms currently demonstrate the submission process but do not send information to an actual email address or database.

Furthermore, I improved the website's Search Engine Optimisation (SEO) by updating the title tags and adding meta descriptions to all six HTML pages, including Home, About Us, Services, Gallery, Booking and Contact. Each page was given a descriptive title and a meta description explaining its content. For example, the Home page title was changed to "Paws & Polish | Professional Dog Grooming Services", while the Services page was given the title "Dog Grooming Services | Paws & Polish". These changes help search engines understand the content of the website and may improve how the pages appear in search results.

I also improved image accessibility and loading performance by checking that the gallery images contained alternative text using the alt attribute. This helps users who rely on screen readers understand what the images represent. I then added the loading="lazy" attribute to the gallery images to allow the browser to delay loading images until they are needed. During testing, I noticed that some of the lazy-loading attributes had been placed incorrectly outside the image tags, causing unwanted text to appear on the Gallery page. I corrected the HTML code and tested the website again to ensure that the images displayed correctly and the lightbox continued working.

Lastly, I tested the website using Google Chrome Developer Tools to check its responsiveness on mobile devices. I used the mobile device view to examine the Home page and confirmed that the navigation, text and images displayed correctly without horizontal scrolling. I also tested the JavaScript features to ensure that the gallery lightbox, search and sorting options, booking form and contact form worked as expected. Overall, the improvements made in Part 3 helped transform the Paws & Polish website from a basic HTML and CSS website into a more interactive and accessible website, while improving its usability, performance and search engine optimisation.
